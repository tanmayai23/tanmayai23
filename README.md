### `04 / THE BUILD PROTOCOL`

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="./assets/build-log-dark.svg">
  <img src="./assets/build-log-light.svg" alt="Define the problem, prototype, measure results, and ship" width="100%">

| Phase | Approach |
|:--|:--|
| **01 / Define** | Understand the user, the constraint, and the actual problem. |
| **02 / Prototype** | Build the smallest system that tests the core assumption. |
| **03 / Measure** | Evaluate quality, latency, cost, and failure cases. |
| **04 / Ship** | Deploy, document trade-offs, and improve using feedback. |

**The rule:** Complexity must earn its place in the architecture.
